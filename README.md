# Operation Faded

Exploratory Fruitbowl prototype for a modern digital presence for **Faded Barbers**, based in Selby.

## Status

This project is at the very start of its process: research and brief first, then visual direction, then architecture, then build. No design or build work has started yet, and no technology stack has been chosen.

This is an independent codebase — it does not reuse or copy any code from other projects, though patterns and lessons from prior work may inform decisions later.
